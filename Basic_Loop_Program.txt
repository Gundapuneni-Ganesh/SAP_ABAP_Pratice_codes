* printing the value 1 to 10

DATA x TYPE I VALUE 0.

    WRITE / SY-INDEX.
ENDDO.

*----------------------------------------------------------------------------------------
* printing the values 1 to 10 by using while loop

WHILE X LT 11.
     WRITE / X .
     X = X + 1.
ENDWHILE.
*-----------------------------------------------------------------------------------------
* Print only even numbers from 1 to 10 using CONTINUE.

DATA y TYPE I VALUE 1.
WHILE y < 11.
     y = y + 1.
     IF y MOD 2 <> 0.
        CONTINUE.
     ENDIF.
     WRITE / y.
ENDWHILE.
