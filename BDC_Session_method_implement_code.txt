* Here we should copy code from that INCLUDE and also copy that structure for that code only . Then  all requred parameters pass to the workarea and insert to that intenal table
* that internal table we pass to the BDC method of CALL TRANSACTION. so from that internal table , method will read by using t-code we mention in that

FORM BDC_DYNPRO USING PROGRAM DYNPRO.                           " This code we copy from the INCLUDE program above define that  while created in Screeen recording
  CLEAR wa_BDCDATA.
  wa_BDCDATA-PROGRAM  = PROGRAM.
  wa_BDCDATA-DYNPRO   = DYNPRO.
  wa_BDCDATA-DYNBEGIN = 'X'.
  APPEND wa_BDCDATA to it_bdcdata.
ENDFORM.

FORM BDC_FIELD USING FNAM FVAL.                                " This code we copy from the INCLUDE program above define that  while created in Screeen recording

    wa_BDCDATA-FVAL = FVAL.
    APPEND wa_BDCDATA to it_bdcdata.
ENDFORM.
